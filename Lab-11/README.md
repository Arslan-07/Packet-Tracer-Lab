# Lab 11 – Network ID, Host ID and Broadcast Address

## 📌 Overview

This lab focuses on understanding Network ID, Host ID, and Broadcast Address in IPv4 networking.

These concepts are essential for understanding how IP addresses are divided into network and host portions and how devices communicate within a network.

## 🎯 Objectives

- Understand IPv4 Network ID and Host ID.
- Identify the Network Address of an IPv4 subnet.
- Calculate the Broadcast Address.
- Understand the role of subnet masks.
- Learn how IP addresses are divided into network and host portions.
- Develop a foundation for subnetting and network design.

## 🛠️ Tools & Technologies

- IPv4 Addressing
- Subnet Masks
- Binary Number System
- Network ID Calculation
- Host ID Identification
- Broadcast Address Calculation

## 📚 Key Concepts

| Concept | Explanation |
|---|---|
| Network ID | Identifies a particular network |
| Host ID | Identifies a device within a network |
| Broadcast Address | Used to send packets to all hosts in a subnet |
| Subnet Mask | Determines the network and host portions of an IP address |

## 🧪 Practical Learning

During this lab, I studied how to identify the Network ID, Host ID, and Broadcast Address using IPv4 addresses and their subnet masks.

I also practiced understanding the relationship between binary values, subnet masks, and network boundaries.
